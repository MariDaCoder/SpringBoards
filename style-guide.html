Section 07 • Naming Conventions & Reusable Modifiers

Global Utility Classes Reference (.u-* & .ds-*)

Global utility classes follow the design system naming convention: .u-[property]-[token] for single-purpose atomic utilities and .ds-[pattern]--[modifier] for composite layout/surface helpers. Click any class name to copy.

Category Global Utility Classes Mapped CSS Token / Behavior

.u-bg-canvas .u-bg-elevated .u-bg-subtle .u-bg-navy .u-bg-accent-tint .u-bg-success-tint
Maps to --color-bg-canvas, --color-bg-elevated, --color-bg-subtle, --color-brand-primary, and semantic status surface tints.
Typography Scale
.u-text-display .u-text-2xl .u-text-xl .u-text-h4 .u-text-lg .u-text-base .u-text-sm .u-text-xs .u-text-numeral

Text & Status Colors
.u-color-primary .u-color-secondary .u-color-muted .u-color-inverse .u-color-accent .u-color-success .u-color-warning .u-color-danger
Maps foreground color directly to WCAG-audited semantic text and status tokens.
Measure & Font Utilities
.u-measure .u-measure-compact .u-font-mono .u-uppercase .u-weight-bold

Provides vertical flex stacks, horizontal wrapping badge/button clusters, space-between headers, and responsive auto-fit grids.
