Section 08 • Base + Modifier Architecture

Combo Classes: Extending Base Classes Without Duplication

Combo classes chain a lightweight modifier (.is-* or --*) onto an existing base class (.sb-card, .btn-primary, .btn-cta, .section-tag, .ds-callout, .program-inquiry-form, .form-input). The base class owns structure, padding, radius, and transitions while the combo class overrides only the specific variation delta.
